Press `?` at any time within the app to open the interactive shortcuts reference with context-aware highlighting.

## Global

| Key | Action |
|-----|--------|
| `?` | Open shortcuts / help modal |
| `Esc` | Close modal or overlay |
| `Cmd/Ctrl+,` | Open Preferences |
| `Cmd/Ctrl+Shift+M` | Toggle Modify mode (RO / Write) |
| `Cmd/Ctrl+W` | Close window |
| `Cmd/Ctrl+Q` | Quit Truss |

## Pane Navigation

| Key | Action |
|-----|--------|
| `Tab` / `Shift+Tab` | Cycle focus across panes |
| `Cmd/Ctrl+1` | Focus Navigator pane |
| `Cmd/Ctrl+2` | Focus Inspector pane |
| `Cmd/Ctrl+↑` | Navigate up (resource → kind → namespace) |

## Command Palette and Search

| Key | Action |
|-----|--------|
| `Cmd/Ctrl+P` or `Cmd/Ctrl+K` | Open command palette |
| `:` | Open command palette (outside text inputs) |
| `/` | Open global search (outside text inputs) |

## Resource List

| Key | Action |
|-----|--------|
| `↑ / ↓` | Navigate resources |
| `Enter` | Open selected resource in inspector |
| `Cmd/Ctrl+Shift+L` | Open Logs window for selected resource |
| `Cmd/Ctrl+Shift+T` | Open Exec window for selected resource |

## Inspector Tabs

| Key | Action |
|-----|--------|
| `Cmd/Ctrl+Shift+S` | Summary tab |
| `Cmd/Ctrl+Shift+E` | Events tab |
| `Cmd/Ctrl+Shift+Y` | YAML tab |

## Session Windows

### Logs Window

| Key | Action |
|-----|--------|
| `Cmd/Ctrl+F` | Find / filter log lines |
| `Cmd/Ctrl+C` | Copy selected text |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Switch log tabs |

### Exec Window

| Key | Action |
|-----|--------|
| `Cmd/Ctrl+Shift+C` | Copy selection |
| `Cmd/Ctrl+Shift+V` | Paste |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Switch exec tabs |
| `Ctrl+C` | Terminal interrupt (SIGINT) — not copy |

### YAML Diff Window

| Key | Action |
|-----|--------|
| `Cmd/Ctrl+S` | Approve / save diff |
| `Esc` | Reject diff |

### Port Forward Window

| Key | Action |
|-----|--------|
| `Cmd/Ctrl+Enter` | Start port-forward |
| `Enter` | Open forwarded URL in browser |
| `Delete` | Stop port-forward |
